Atualiza o fluxo de todas as arestas pertencentes ao caminho aumentante encontrado.

  • Percorre o caminho encontrado e atualiza o fluxo com base no valor de gargalo fornecido. Se a aresta for atravessada no seu sentido original, o fluxo é somado. Se for atravessada no sentido inverso (aresta residual), o fluxo é subtraído.

◆ edmondsKarp()

Algoritmo Edmonds-Karp para calcular o Fluxo Máximo.

  • Este é o algoritmo principal. Inicializa o fluxo do grafo a zero e, iterativamente, procura caminhos aumentantes através da BFS, atualizando o fluxo máximo da rede até não existirem mais caminhos possíveis entre a origem e o destino.
  • Template Parameters
    TTipo de dado armazenado no vértice.
    Parameters
    gApontador para o grafo da conferência.
    sourceInfoInformação (ID) do nó de origem (ex: "SOURCE").
    targetInfoInformação (ID) do nó de destino (ex: "SINK").
  • Time Complexity
    \(\mathcal{O}(V \cdot E^2)\), onde \(V\) é o número de vértices e \(E\) é o número de arestas. O algoritmo encontra no máximo \(\mathcal{O}(V \cdot E)\) caminhos aumentantes, e a busca de cada caminho custa \(\mathcal{O}(E)\) com a BFS.

Vertex< T > * s,

Procura um caminho aumentante (Augmenting Path) no grafo residual.

  • Utiliza o algoritmo de Busca em Largura (BFS - Breadth-First Search) para encontrar o caminho mais curto (em número de arestas) desde o nó origem (source) até ao nó destino (sink) no grafo residual.
  • Template Parameters
    TTipo de dado armazenado no vértice.
    Parameters
    gApontador para o grafo.
    sVértice de origem (Source).
    tVértice de destino (Sink).
    Returns
    true Se encontrou um caminho aumentante até ao destino.
    false Se não encontrou nenhum caminho (o fluxo máximo foi atingido).
  • Time Complexity
    \(\mathcal{O}(V + E)\) no pior cenário, onde \(V\) é o número de vértices e \(E\) é o número de arestas.

◆ findMinResidualAlongPath()

template<class T>
double findMinResidualAlongPath ( Vertex< T > * s,
Vertex< T > * t )

Calcula a capacidade de gargalo (bottleneck) de um caminho aumentante.

  • Percorre de trás para a frente o caminho encontrado pela BFS (seguindo os ponteiros path), e descobre o valor mínimo de capacidade residual entre todas as arestas que compõem o caminho.
  • Template Parameters
    TTipo de dado armazenado no vértice.
    Parameters
    sVértice de origem (Source).
    tVértice de destino (Sink).
    Returns
    double O valor do estrangulamento (fluxo máximo que pode passar por este caminho específico).
  • Time Complexity
    \(\mathcal{O}(V)\), onde \(V\) é o número de vértices, pois o caminho mais longo possível num grafo não tem ciclos e percorre no máximo \(V-1\) arestas.

Função auxiliar para testar e visitar um nó adjacente.

  • Esta função verifica se um nó ainda não foi visitado e se existe capacidade residual suficiente para passar fluxo. Se ambas as condições se verificarem, o nó é marcado como visitado, guarda a aresta pela qual foi alcançado e é colocado na fila da BFS.
  • Template Parameters
    TTipo de dado armazenado no vértice.
    Parameters
    qFila (queue) utilizada pela BFS.
    eAresta que liga o nó atual ao nó destino.
    wNó destino a ser testado.
    residualCapacidade residual atual da aresta.
  • Time Complexity
    \(\mathcal{O}(1)\) - A verificação e inserção na fila operam em tempo constante.
